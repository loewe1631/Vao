# Mac software updates

The Mac app offers **Check for updates** in About. It checks only on request, displays release notes, downloads and verifies the archive, then shows explicit in-app confirmation and cancellation before restarting and installing. It does not depend on native JavaScript confirm dialogs. Voice input and pending insertion must be finished first. Settings, dictionary, history and Keychain are outside the App bundle and are not replaced.

The production feed is `https://updates.vaovao.app/macos/stable.json`. A missing/unreachable feed is an explicit check failure, never a claim that the installed app is up to date. Publishing a normal ZIP does not create an update: deploy the signed manifest to /macos/stable.json and its exact archive under /downloads/. GitHub retains the release assets and source as a separate backup; the client does not fall back to GitHub. Users of 0.2.2 or earlier must install manually. The 0.2.3 release and affected early previews have an unresponsive install confirmation and also require a one-time manual installation of 0.2.4. Do not delete app data.

The manifest envelope contains base64 `signed` and `signature` strings. `signed` is UTF-8 JSON schema 1: version, build, notes, URL, SHA256, byte size, minimum macOS, architecture, bundle and Developer ID team. `signature` is a base64-encoded Minisign Ed25519 prehashed signature over those exact bytes. `desktop/src/updater-public-key.txt` is the public verification key; the private key is never packaged or checked into Git. Signatures protect the version and hash as well as the archive. An older version, or the same version with an equal/lower build, is not installed. The production feed rejects prerelease versions.

Downloads require HTTPS from updates.vaovao.app only, without a GitHub download dependency, bounded sizes and timeouts. Before replacement, the app checks the signed archive hash and size, safe archive entries, matching bundle/version/build/arm64, strict Developer ID for both executables and Gatekeeper. Archives use one `Vao.app` root, regular files/directories and no links. The App is staged beside the installation for same-volume renames; the old bundle is retained as `.Vao-update-*/previous.app`. A failed second rename restores the original; an unrecoverable restore error preserves the backup for manual recovery. A crash after installation is not an automatic launch rollback.

App Translocation or an unwritable installation folder requires moving Vao to a writable Applications folder. The updater does not request administrator credentials or modify system permissions. Test another Mac's first download, permissions and a future public-feed update separately.

For a release, first build with Developer ID, obtain Apple Accepted, staple and validate the final App. Run `python3 scripts/sign-macos-update.py --help` and supply the signing key **path**, exact Cloudflare download URL and notes file. It produces the archive, signed manifest and identity record locally; it never publishes. Keep the existing user-download ZIP as well. Back up the private update key securely; losing it requires a manually installed version carrying a replacement public key.

`--verify-update-feed isolated-config.json` is an explicit diagnostic with a `.vao-updater-fixture` marker, a fixed `install/Vao.app` below that directory, and loopback HTTPS. A supplied test CA is trusted only by this single call's HTTP client; it does not enter the system trust store or production updater. It never opens production app data or credentials. This mode tests the same download, verification, extraction and replacement functions on an isolated App copy; it is not a user acceptance or public-feed test.

Cloudflare Pages project `vao-updates` serves the update subdomain separately from the website project. Deploy only the reviewed public update directory. The stable manifest must use `Cache-Control: no-store`; versioned archives may use immutable caching and must never be overwritten. Preserve all old downloads on each deployment. Complete and verify the archive before promoting the stable manifest; a single static deployment makes the switch atomic. Missing paths must return 404 rather than an HTML SPA fallback. A future Windows-only GitHub latest release does not affect this Mac feed.

Native Mac GUI acceptance must cover discovery, download, cancellation, confirmation, replacement and relaunch; Chromium dialogs and isolated CLI fixtures do not certify the WKWebView integration. Cloudflare delivery does not guarantee availability on every mainland-China network; test those networks separately.
