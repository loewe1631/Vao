# 自有宿主 TSF 基础原型

本工具只在 GitHub Windows 自有隐藏窗口内验证文本服务；没有接入 Vao 日用路径，也不获取其他应用的 ITfContext。没有注册 DLL、语言 Profile 或更改默认输入法，没有 SendInput、剪贴板、音频、模型或跨进程 IPC。它不是可以修复 WPS 的安装包，暂不传笔记本运行。

用真实 ITfThreadMgrEx / ITfDocumentMgr / ITfContext、ITextStoreACP 及同步编辑会话验证 UTF16 全文/选区读取、读写锁与编辑 cookie、选区替换、插入后完整正文/光标收据、一次性共享 token、上下文身份/失效/取消/过期及内容/光标冲突。字段内容仅来自固定自有 fixture，保留在内存；报告只有测试项、数值和布尔状态，不导出正文或其散列。

每份可提交正文和结果最多4096个UTF16单元，拒绝未配对代理项、切开代理对的选区、嵌入对象、只读/密码/组合输入状态。密码及组合输入判断是自有宿主策略，尚未证明可从 WPS 获得这些状态。宿主提供基础异步锁合并；本阶段只验收同步会话，不宣称完成异步锁/IME兼容。

ActivateEx仅延迟TIP激活和初次键盘布局同步；这两个标志并不保证未来线程获得操作系统焦点时不会激活TIP。因此本原型不展示或请求前台/键盘焦点，且核查测试前后的前台窗口和键盘布局。TSF逻辑文档焦点只在本线程创建的两个自有DocumentMgr间切换，最后Deactivate。

未验收：外部WPS上下文、文档格式/大文档/undo、安全IPC、进程内文本服务DLL/Profile注册及激活。这些需要后续独立交付和现场证据，不能以本原型通过替代。
