# 文字接口能力检查

这是一款独立只读工具，不替换 Vao，也不输入固定短句。

关闭旧的输入验证器，双击 Start-Capability-Check.cmd。看到“已就绪”后，在 WPS 测试文档中点击文字位置，按 Ctrl+Alt+F8，等待约5秒即可。无需F9、无需上传报告，关闭窗口退出。Vao 3007 可继续保留；若提示热键不可用，先退出旧的 F8/F9 输入验证器。

检查仅从此刻焦点向上查询同一窗口中的祖先，最多8个节点，单次子进程最长5秒。不扫描其他窗口，不恢复/切换焦点，不接麦克风、模型、剪贴板或输入法。日志只有模式能力、进程ID、控件类型及数值/布尔状态，没有正文、名称、标题、选区内容或散列。未能证明同根窗口、焦点变化、密码或超时均停止，不导出局部节点。

即使查到 Text / Text2 / TextEdit / Value，也只证明这一提供者暴露了接口，不证明能够精确定位文档、保留格式、正确输入或核验收据。工具不调用文字读取、选区读取或任何文字/光标写入接口，不包含按应用名放行逻辑。
